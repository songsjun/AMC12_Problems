==Problem 10==
The tree diagram below has nodes labeled with rational numbers. The top node, at level <imath>0</imath>, is <imath>\frac{1}{2}</imath>. Each node <imath>\frac{a}{b}</imath> sprouts two nodes in the level below it, <imath>\frac{a}{a+b}</imath> and <imath>\frac{b}{a+b}</imath>. For example, level <imath>1</imath> has nodes <imath>\frac{1}{1+2} = \frac{1}{3}</imath> and <imath>\frac{2}{1+2} = \frac{2}{3}</imath>.

<asy>
unitsize(1.2cm);

// ============================================================
// 1. GEOMETRY PARAMETERS
// ============================================================

// Vertical distances.
real edgeDrop      = 0.8;  // Length of ordinary branches.
real labelGap      = 0.65; // Gap between branch tips and next label row.
real finalEdgeDrop = 0.42; // Length of the final branches.

// Horizontal distances between a parent and either child.
// Index 0 corresponds to the first branching level.
real[] branchOffset = {2.0, 1.0, 0.5, 0.28};

// Drawing styles.
pen branchPen = black + linewidth(1);
pen textPen   = black;

// ============================================================
// 2. REUSABLE DRAWING FUNCTIONS
// ============================================================

// Draw two downward branches from each parent.
//
// Returns the x-coordinates of the children, ordered
// left-to-right within each parent's pair.
real[] drawChildren(real[] parentX, real parentY,
                    real horizontalOffset, real verticalDrop) {

    real[] childX = new real[2*parentX.length];

    real childY = parentY - verticalDrop;

    for (int i = 0; i < parentX.length; ++i) {

        // Coordinates of the two children.
        real leftX  = parentX[i] - horizontalOffset;
        real rightX = parentX[i] + horizontalOffset;

        childX[2*i]   = leftX;
        childX[2*i+1] = rightX;

        // Draw the two outgoing arrows.
        draw((parentX[i], parentY)--(leftX, childY),
             branchPen, arrow=Arrow(TeXHead));

        draw((parentX[i], parentY)--(rightX, childY),
             branchPen, arrow=Arrow(TeXHead));
    }

    return childX;
}

// Place a row of fraction labels.
//
// The x-coordinates and fraction labels must have
// matching lengths and be listed from left to right.
void labelLevel(real[] x, real y, string[] fractions) {

    for (int i = 0; i < x.length; ++i) {
        label("$" + fractions[i] + "$",
              (x[i], y), N, textPen);
    }
}

// ============================================================
// 3. FRACTION LABELS
// ============================================================

// Each array corresponds to one level of the tree.
// Children are ordered from left to right.

string[] level0 = {
    "\frac{1}{2}"
};

string[] level1 = {
    "\frac{1}{3}",
    "\frac{2}{3}"
};

string[] level2 = {
    "\frac{1}{4}", "\frac{3}{4}",
    "\frac{2}{5}", "\frac{3}{5}"
};

string[] level3 = {
    "\frac{1}{5}", "\frac{4}{5}",
    "\frac{3}{7}", "\frac{4}{7}",
    "\frac{2}{7}", "\frac{5}{7}",
    "\frac{3}{8}", "\frac{5}{8}"
};

// ============================================================
// 4. VERTICAL POSITIONING
// ============================================================

// Distance between consecutive rows of fraction labels.
real rowStep = edgeDrop + labelGap;

// Vertical coordinates of the four labelled levels.
real y0 = 0;
real y1 = y0 - rowStep;
real y2 = y1 - rowStep;
real y3 = y2 - rowStep;

// ============================================================
// 5. GENERATE THE TREE
// ============================================================

// Level 0: Root.
real[] x0 = {0};
labelLevel(x0, y0, level0);

// Level 1: Two children.
real[] x1 = drawChildren(
    x0, y0, branchOffset[0], edgeDrop
);
labelLevel(x1, y1, level1);

// Level 2: Four children.
real[] x2 = drawChildren(
    x1, y1, branchOffset[1], edgeDrop
);
labelLevel(x2, y2, level2);

// Level 3: Eight children.
real[] x3 = drawChildren(
    x2, y2, branchOffset[2], edgeDrop
);
labelLevel(x3, y3, level3);

// ============================================================
// 6. FINAL BRANCHES AND CONTINUATION MARKS
// ============================================================

// Draw the final, shorter pair of arrows from each level-3 node.
for (int i = 0; i < x3.length; ++i) {

    draw((x3[i], y3)--(x3[i]-branchOffset[3],
                       y3-finalEdgeDrop),
         branchPen, arrow=Arrow(TeXHead));

    draw((x3[i], y3)--(x3[i]+branchOffset[3],
                       y3-finalEdgeDrop),
         branchPen, arrow=Arrow(TeXHead));
}

// Place vertical continuation marks below the final labelled row.
real dotsY = y3 - finalEdgeDrop - labelGap;

for (int i = 0; i < x3.length; ++i) {
    label("$\vdots$", (x3[i], dotsY), N, textPen);
}
</asy>
