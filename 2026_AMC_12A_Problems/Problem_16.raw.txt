==Problem==
Gerry is playing the Triples Game. Her task is to partition the <imath>3\times 3</imath> grid of squares shown on the left into three sections, each containing three adjoining squares. (Three squares are adjoining if each shares an edge with at least one of the other two.) One point will be awarded for each section containing more <imath>\mathsf{X}</imath>'s than <imath>\mathsf{O}</imath>'s. Shown on the right is a sample partition that will earn one point in total. A partition that earns two or more points will win the game. What fraction of the possible partitions of this particular grid will result in a win for Gerry?

<asy>
unitsize(0.62cm);
string[][] m = {{"X","O","X"},{"X","X","O"},{"O","O","O"}};
pen thick = linewidth(1);
pen redpen = rgb(0.85,0,0) + linewidth(2.5) + miterjoin + squarecap;
for (int s = 0; s < 2; ++s) {
real x0 = 5.5*s;
for (int k = 0; k <= 3; ++k) {
draw((x0+k,0)--(x0+k,3), s == 0 ? thick : defaultpen);
draw((x0,k)--(x0+3,k), s == 0 ? thick : defaultpen);
}
for (int r = 0; r < 3; ++r)
for (int c = 0; c < 3; ++c)
label("\textsf{" + m[r][c] + "}", (x0+c+0.5, 2.5-r));
}
draw((5.5,0)--(8.5,0)--(8.5,3)--(5.5,3)--cycle, redpen);
draw((7.5,0)--(7.5,3), redpen);
draw((7.5,2)--(6.5,2)--(6.5,1)--(5.5,1), redpen);
</asy>

<imath>\textbf{(A)}~\frac{3}{10} \qquad \textbf{(B)}~\frac{1}{3} \qquad \textbf{(C)}~\frac{2}{5} \qquad \textbf{(D)}~\frac{4}{9} \qquad \textbf{(E)}~\frac{1}{2}</imath>

==Solution 1==

There are four corner squares but only three sections, so some section contains two corners. A connected section of three squares containing two corners must be a complete outer row or column.

Removing it leaves a <imath>2\times3</imath> rectangle, which splits into either two straight sections or two L-shaped sections. There are <imath>2</imath> all-straight partitions (rows or columns). Otherwise, choose the single straight section on one of the <imath>4</imath> sides, then split the remaining rectangle into two L-shapes in <imath>2</imath> ways. Thus there are
<cmath>
2+4\cdot2=10
</cmath>
partitions in total.

Since there are only <imath>4</imath> X's, a win requires exactly <imath>2</imath> X's in each of two sections. All <imath>10</imath> partitions are shown below; exactly <imath>4</imath> win.

<asy>
unitsize(0.6cm);
defaultpen(fontsize(10pt));
string[] symbols={"X","O","X","X","X","O","O","O","O"};

void board(pair p, int[] g, bool win) {
  for(int k=0; k<=3; ++k) {
    draw((p+(k,0))--(p+(k,3)),gray(0.75));
    draw((p+(0,k))--(p+(3,k)),gray(0.75));
  }
  for(int r=0; r<3; ++r) {
    for(int c=0; c<3; ++c) {
      int k=3*r+c;
      label(symbols[k],p+(c+0.5,2.5-r));
      if(c>0 && g[k]!=g[k-1])
        draw((p+(c,2-r))--(p+(c,3-r)),linewidth(1.5));
      if(r>0 && g[k]!=g[k-3])
        draw((p+(c,3-r))--(p+(c+1,3-r)),linewidth(1.5));
    }
  }
  draw(p--(p+(3,0))--(p+(3,3))--(p+(0,3))--cycle,linewidth(1.5));
  if(win) label("\textbf{Win}",p+(1.5,-0.2),S,blue);
  else label("Lose",p+(1.5,-0.2),S,gray(0.5));
}

string[] titles={"All straight","Top row","Bottom row","Left column","Right column"};
for(int j=0; j<5; ++j)
  label(titles[j],(4.2*j+1.5,7.8),N);

board((0,4.4),new int[]{1,1,1,2,2,2,3,3,3},true);
board((0,0),new int[]{1,2,3,1,2,3,1,2,3},false);

board((4.2,4.4),new int[]{1,1,1,2,2,3,2,3,3},true);
board((4.2,0),new int[]{1,1,1,2,3,3,2,2,3},false);

board((8.4,4.4),new int[]{1,1,2,1,2,2,3,3,3},true);
board((8.4,0),new int[]{1,2,2,1,1,2,3,3,3},false);

board((12.6,4.4),new int[]{1,2,2,1,2,3,1,3,3},true);
board((12.6,0),new int[]{1,2,2,1,3,2,1,3,3},false);

board((16.8,4.4),new int[]{1,1,2,1,3,2,3,3,2},false);
board((16.8,0),new int[]{1,1,2,3,1,2,3,3,2},false);

draw((-0.35,-0.9)--(20.15,8.6),invisible);
</asy>

Therefore, the requested fraction is
<cmath>
\frac{4}{10}=\boxed{\frac25},
</cmath>
We choose <imath>\boxed{\textbf{(C)}}</imath>.

==Solution 2==
Consider the section that includes the bottom-right square. Note that it will always have two O's, so whatever section contains it will be invalid. We casework over all the possible sections, and look at how we can split the remaining 6 tiles for each. This makes it easier to count, as now both the other sections must have more X's than O's to win, and we are sure that we have covered all the cases. Proceed as Solution 1.

==Solution 5==

First, we count the number of total partitions. Consider the "<imath>l</imath>" shape formed by three squares. We see that if we fix any "<imath>l</imath>" that contains the center square, the rest is uniquely determined. There are 8 such "<imath>l</imath>"s, but we have to also account for the case where there are 3 vertical lines and 3 horizontal lines. These account for 10 partitions in total.

Now, we count the number of winning partitions. Let the square directly to the left of the center square be called the penguin square.

Case 1: Center and penguin square are together in a winning partition. We can see it either has to be horizontal or containing the bottom-left square, and the rest are uniquely determined, for a total of 2 cases.

Case 2: Center and penguin square are disjoint in a partition. We see that the center square has to be in the partition with the top-right square, and then the rest are uniquely determined, for a total of 2 cases.

<imath>\frac{2+2}{10} = \boxed{\textbf{(C)}~\frac{2}{5}}</imath>.

==Solution 7==
For each section that gains a point, it must have atleast 2 X's as if it only has maximum one X, it will have at least 2 O's and not count. So that means (a) max 2 points can be gained and (b) there must be one section with only O's as otherwise there are only maximum 3 X's and only one point can be gained. There are 2 ways this can be achieved: either you use the bottom row of O's and then you have 3 ways, either 3 rows, or the bottom row and 2 L-shapes which can be oriented in 2 ways. The 3 rows and one orientation of the L-shapes work, so we get 2 cases. The other case is the bottom L-shape of 3 O's and any of the 2 ways from here works. So in total there are 4 ways that work, and to count the total ways, we have 2 ways of only 3 rows or 3 columns, and then we have the ones with the L-shapes: one line in any direction gives 2 orientations of the L-shapes and there are 2 rows and 2 columns that allow L-shapes, which makes <imath>2\cdot4=8</imath> ways so in total we have <imath>2+8=10</imath> ways so our answer is <imath>\frac{4}{10}</imath> which simplifies to <imath>\boxed{\text{(C) }\frac{2}{5}}</imath>.
~keyo
