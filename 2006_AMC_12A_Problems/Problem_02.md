# 2006 AMC 12A Problem 2

> This problem is the same as [2006 AMC 12A #2](https://artofproblemsolving.com/wiki/index.php/2006_AMC_12A_Problems) and [2006 AMC 10A #2](https://artofproblemsolving.com/wiki/index.php/2006_AMC_10A_Problems/Problem_2).
## Problem
Define $x\otimes$ y=x^3-y. What is $h\otimes (h\otimes$ h)?

$\textbf{(A)}\ -h\qquad\textbf{(B)}\ 0\qquad\textbf{(C)}\ h\qquad\textbf{(D)}\ 2h\qquad\textbf{(E)}\ h^3$
## Solution 1
By the definition of $\otimes,$ we have $h\otimesh=h^{3}$-h.

Then, $h\otimes (h\otimes$ h)=h$\otimes (h^{3}-h)=h^{3}-(h^{3}-h)=\boxed{\textbf{(C) }h}.$
