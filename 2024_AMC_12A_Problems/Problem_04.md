# 2024 AMC 12A Problem 4

> This problem is the same as [2024 AMC 10A #5](https://artofproblemsolving.com/wiki/index.php/2024_AMC_10A_Problems/Problem_5) and [2024 AMC 12A #4](https://artofproblemsolving.com/wiki/index.php/2024_AMC_12A_Problems/Problem_4).
## Problem
What is the least value of $n$ such that $n!$ is a multiple of $2024$?

$\textbf{(A) } 11\qquad\textbf{(B) } 21\qquad\textbf{(C) } 22\qquad\textbf{(D) } 23\qquad\textbf{(E) } 253$
## Solution
Note that $\cdot11\cdot23$ in the prime factorization. Since $23!$ is a multiple of $2^3, 11,$ and $23,$ we conclude that $23!$ is a multiple of $2024.$ Therefore, we have $n=\boxed{\textbf{(D) } 23}.$

<u><b>Remark</b></u>

Memorizing the prime factorization of the current year is useful for the AMC 8/10/12 Exams.
